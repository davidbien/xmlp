# The tests of the W3C XML Conformance Test Suite which xmlp is known not to pass - see DtdConformance/Suite in xmlpgtest_dtd.cpp.
# A line is: how the document was read, the ID of the test in the catalog of the suite, and why. How it was read:
#  V   by a validating cursor with its external entities - the document as it is.
#  N   by a cursor which doesn't validate, without its external entities.
#  C   what is read compared with the canonical form which the suite has of the document.
#  R   what the writer writes from it, read again, compared with the document.
#  16  as V, the document converted to UTF-16.   32  as V, converted to UTF-32.
# The test fails if a document which is not listed fails - and if one which is listed no longer does: then its line is to be taken away.
